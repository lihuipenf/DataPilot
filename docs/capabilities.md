# 能力边界与使用约定

适用实现：**v1.3.1**。本文集中说明实际支持范围，不是未来功能承诺。[文档导航](README.md) · [当前进度](progress.md) · [安全报告](../SECURITY.md)

## 可以完成的任务

DataPilot 用于结构化销售CSV的本地探索：通过11个受控工具查询总额、商品/日期汇总、排名、业务指标和只读SQL，生成商品柱状图或每日趋势图，并导出Markdown报告、商品汇总CSV与PNG。网页支持会话历史恢复和上下文追问。

| 方面 | 支持范围 | 限制与前提 |
|---|---|---|
| 数据输入 | 当前会话的一份销售CSV | 固定字段契约；没有Excel工作簿、PDF、网页采集或任意文件分析入口 |
| 数值分析 | 销售额、销量、记录数、日期/商品汇总、已定义均价 | 没有订单ID、成本、库存等字段时，不能计算真实订单数、客单价、利润或库存 |
| 自然语言 | 实时模型选择工具、组织答案，支持有界追问 | 可能误解日期、指标或商品名，也可能给出错误解释；重要结论需核对工具参数和结果 |
| SQL | 当前CSV转换的独立内存sales表，单条受限只读查询 | 无外部数据库连接、写操作、外部文件访问或任意Python执行；不是通用代码沙箱 |
| 可视化 | 商品销售额柱状图、每日销售额趋势图 | 当前工具没有任意图表设计、交互式BI仪表盘或预测模型 |
| 会话 | 本地SQLite保存网页数据、问答和执行证据 | 单用户、单进程；不是多人账号、权限隔离、跨进程任务系统或公网托管服务 |
| 交付 | 本地网页、CLI、源码包和Docker Compose | Python 3.12为验证版本；Windows原生与Linux容器有验证，macOS原生全流程未实跑 |

## 输入与业务口径

- CSV必须含`date,product,quantity,unit_price`，编码为UTF-8、UTF-8 BOM或GB18030；最多5 MiB、50000行、64列。额外列检查结构后忽略，不会自动变成可分析业务字段。
- 日期为有效`YYYY-MM-DD`，没有时间点或时区分析。商品名非空、最多120字符；编号按文本保留，首尾空白会清理。
- 数量为非负整数，单价为有限非负数，两者各不超过10^12；总销售额不超过10^18。负数退货记录、缺失必要值与不合格数据会被拒绝。
- 销售额由数量×单价重新计算；现有金额运算使用浮点数并在展示/汇总时按实现保留两位，不是精确十进制财务账本。
- 未提供币种、折扣、税率、成本或订单ID时不推断这些信息；不执行汇率转换、利润核算或因果归因。数据中的相关趋势也不能证明促销造成了销售变化。
- 日期统计最多366个有记录日期；未出现的日期不自动等于零销售。图表最多20个商品或最近366个有记录日期。大规模并列仅列出部分名称并标记截断。

## 离线演示、模型支持与验证证据

**离线演示**是固定规则路由加真实Pandas/SQLite计算，用于无密钥体验和可重复演示。它不理解任意自然语言，SQL演示采用固定查询模板；26/26离线通过不代表LLM准确率。

**实时模式**支持DeepSeek/OpenAI兼容Chat Completions、OpenAI Responses和Claude Messages协议。模型与账号必须具备相应API权限和工具调用能力；不读取桌面Codex、Claude Code或其他订阅登录，不保证任意第三方兼容服务都可用。

当前发布的100项自动化回归包含模拟外部模型响应的协议/控制流程测试。历史DeepSeek真实评测基于固定5行样例；未把它外推为新业务数据、其他型号、Claude或OpenAI的实测准确率。实际范围与原始结果见 [评测记录](evaluation.md)。

工具返回的计算证据与最终回答要分别核对：工具计算正确，不等于模型选对了范围、口径，或据此给出的建议一定正确。缺少数据时应解释限制，而不是补造数字、预测或商业原因。

## 数据去向与访问控制

- 原生离线演示不调用外部模型；首次安装依赖、下载源码或构建镜像仍需联网。
- 实时模式会把问题、必要历史和工具结果发给所选端点，SQL结果可能包含原始行。不能把“本地计算”理解为“所有数据都不会离开电脑”。只使用自己有权发送给该服务的数据。
- 服务端配置的模型凭据不主动进入网页、报告和会话；但用户若把密钥写进问题或CSV，它仍可能作为输入内容被保存、导出或发送。因此不要在数据和聊天中放凭据。
- 会话与业务数据以本地明文保存，依赖文件系统权限；没有应用级加密或自动脱敏。
- 默认回环监听，没有用户认证，同机其他进程仍可访问API。Origin/Host防护不是多用户权限机制。Docker宿主机端口使用`127.0.0.1:8765:8765`；外部访问需另行配置认证和访问控制。
- 云模型调用可能产生费用，Token/费用估算不等于最终账单；取消不能保证供应商停止计费。

## 容量、截断与停止行为

以下是默认值和执行约束，不是吞吐量、并发容量或可用性SLA：

| 项目 | 当前约束 |
|---|---|
| 单次提问 | 最多2000字符 |
| 工具循环 | 最多4轮工具选择、8次工具执行，随后仅生成回答 |
| 上下文 | 最近6个完整轮次；规范化消息和schema合计24000字符，单工具结果默认8000字符；字符数不是Token数 |
| SQL输出 | 最多200行、单字段2000字符；结果行与列名UTF-8 JSON累计256 KiB；执行器默认1秒检查期限，不是进程级CPU/内存沙箱 |
| 模型调用 | 每步骤最多2次HTTP尝试，默认单次超时45秒，整轮协作式预算120秒 |
| 网页状态 | 内存/待创建槽位32个，默认持久会话200个；展示最近50条问答 |
| 图表存储 | 默认每会话100张PNG，输出目录PNG总量256 MiB；达到配额拒绝新增，不自动删除旧文件 |

超大工具列表按完整行截断并标记`truncated`，SQL的`row_count`表示实际返回行数，不是全表数量；已返回部分不能当成完整清单。范围过大时应缩小查询，不承诺所有合法查询都能在上下文预算内完成。

“停止分析”和时间预算在步骤边界检查；正在进行的同步网络请求、持续流入的响应或锁等待不保证立即中断。失败、超时或确认取消后不提交不完整对话；已生成的文件可能保留。没有SSE/流式生成、强制终止工作进程或完整断线自动取消协议。

改变数据或重置当前对话会清除该会话的逻辑分析历史，不等同于安全擦除磁盘或删除全部已生成图表；切换模式/模型会创建新会话并保留旧会话。程序没有历史数据版本备份功能，使用者应自行备份`.env`与完整`outputs/`。
