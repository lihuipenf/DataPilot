# 当前能力与项目进度

适用版本：**v1.3.1**，更新日期：2026-11-06。[文档导航](README.md) · [发布说明](releases/v1.3.1.md)

使用前请先阅读 [能力边界与使用约定](capabilities.md)，其中列出输入契约、模型验证范围、数据去向和资源/取消限制。

## 已交付

| 方面 | 当前实现 | 验证方式 |
|---|---|---|
| Agent与工具 | 11个参数校验工具、有界多步调用、上下文追问、完整轮次提交 | 自动化控制流程与真实Pandas/SQL测试 |
| 分析 | 总额、商品/日期查询、排名、指标口径、受限只读SQL与图表 | 固定字段断言、三个合成案例及离线题集 |
| 模型 | DeepSeek、OpenAI/Codex、Claude、OpenAI兼容服务的协议适配 | SDK/HTTP协议测试；实际付费验证范围见历史评测 |
| 网页与导出 | CSV上传、预览、工具与SQL依据、历史恢复、Markdown/CSV/PNG导出 | HTTP集成与Chromium验证 |
| 稳定性 | 数据质量检查、JSON大小限制、消息/schema预算、明确截断、协作式停止 | 异常边界及取消/超时回归 |
| 状态与资源 | SQLite持久化、细粒度会话锁、连接回收、会话/图表配额 | 重启、并发、失败回滚与配额测试 |
| 发布 | 通用启动、带哈希锁定依赖、Docker、CI、MIT与安全报告邮箱 | 安装/容器验证、源码ZIP与敏感文件检查 |

v1.3.1发布回归为100项自动化测试、26/26离线规则题。离线成绩不表示大模型准确率；DeepSeek历史真实评测使用固定5行样本，Claude/OpenAI等协议验证不等同于实际付费评测。参见 [评测记录](evaluation.md)。

## 仍未实现或不承诺的范围

- 没有多用户认证、租户隔离或公网托管服务；保持本地单用户、单进程部署。
- 没有SSE/模型流式输出、任务队列或立即强制中断供应商请求。停止与整轮预算是协作式检查。
- 未声明支持任意CSV业务结构、外部生产数据库连接或大规模业务泛化；当前是固定销售字段契约。
- 没有自动删除会话/图表的清理器；配额满时拒绝新增，由使用者备份后处理。
- 未对所有模型做真实付费评测；没有承诺macOS原生全流程已实跑。
