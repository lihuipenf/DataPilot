# DataPilot v1.3.0

上传销售CSV，用自然语言查询销售额、排名与日期趋势，查看工具/SQL依据，并导出报告和图表。内置离线规则演示，无需API Key即可体验；Python 3.12，无需Node.js或前端构建。

## 相对上一个Release的主要更新

- 支持DeepSeek、OpenAI/Codex、Claude及OpenAI兼容服务，按会话保存模型来源。
- 统一上下文与工具结果预算，长结果按完整行截断并明确提示；模式/模型切换保留原会话历史。
- 修复SQL结果资源消耗、宽CSV解析、报告注入和异常请求；限制远程模型地址为HTTPS，HTTP只允许回环端点。
- 改善并发恢复和上传保存，回收SQL/SDK连接；增加会话与图表配额，以及协作式停止。
- 通用启动教程、三个合成数据案例、MIT许可证和私下漏洞报告政策。
- 锁定依赖附带跨平台SHA-256哈希；CI覆盖自动化测试、离线评测、依赖漏洞扫描、静态高危检查及Docker启动/打包排除验证。

## 安装和升级

首次使用请按 [启动教程](../getting-started.md) 安装，或直接使用Docker Compose。Release附带源码ZIP及其`.sha256`校验文件；ZIP包含LICENSE和SECURITY.md，不包含.env、真实运行数据、虚拟环境或会话数据库。

升级前停止服务，备份本地`.env`和完整`outputs/`。更新源码后重新安装`requirements-lock.txt`，保留自己的配置，然后重启。不要用.env.example覆盖已有密钥。

兼容性变化：远程模型端点必须HTTPS；环境代理默认不读取，需要时显式设`DATAPILOT_TRUST_ENV=true`；`/mode` API返回新会话ID；默认配额为200个持久会话、每会话100张PNG和输出目录PNG总量256MiB，满额后拒绝新增，不自动删除旧数据。

## 验证与使用边界

发布检查包含99项自动化回归、26条离线规则评测，以及CI的Linux安装和Docker冒烟测试。离线通过率不代表真实模型准确率；未对所有服务商进行实际付费评测。

项目面向单进程、单用户本地使用，没有多用户认证。Docker宿主机端口保持回环绑定；停止分析为协作式取消，不能保证立即中断供应商已接受的请求。

发现漏洞请按 [SECURITY.md](../../SECURITY.md) 的邮箱私下报告。完整变更见 [CHANGELOG](../../CHANGELOG.md)。v1.1.0保留为历史版本，推荐新用户使用本版本。
