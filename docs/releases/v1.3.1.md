# DataPilot v1.3.1

本次补丁统一应用版本与对外文档。销售分析、模型协议和数据结构延续v1.3.0；已发布的旧标签与附件保留。

## 变化

- 以datapilot.__version__为唯一应用版本来源，健康接口、OpenAPI、网页显示一致。
- 更新中英文README、启动教程、架构、进度、学习路线和演示/简历说明；提供文档导航，统一为11个工具与当前使用边界。
- 旧安全报告和模型评测标明历史适用范围，保留73/82/98/99等当时计数；当前发布回归为100项测试、26条离线规则题，不把它们视为LLM准确率。
- 使用实际v1.3.1工作台截图；源码包继续包含MIT许可证、安全政策和三个合成案例，附SHA-256校验文件。

## 使用与升级

见 [启动教程](../getting-started.md) 和 [文档导航](../README.md)。已有v1.3.0用户更新代码后重启即可；本次没有改变运行依赖或会话数据格式。保留.env及完整outputs，勿覆盖本地配置和数据。

应用仍是没有多用户认证的本地单用户项目；Docker宿主机端口仅绑定回环地址。停止分析是协作式取消，不能保证立即终止供应商已接受的同步请求。真实模型验证范围见 [历史评测](../evaluation.md)。

安全漏洞按 [SECURITY.md](../../SECURITY.md) 私下报告；变更记录见 [CHANGELOG](../../CHANGELOG.md)。
