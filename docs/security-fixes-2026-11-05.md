## 边界

这些预算限制的是当前结果的读取和输出，不是SQL执行的完整进程内存上限；SQLite内部计算仍有独立资源开销。Markdown安全结果依赖阅读器遵循标准代码围栏和实体处理，未穷举所有第三方阅读器。

持久会话/图表空间配额仍是此前记录的独立改进项，本次没有删除历史会话或业务文件。未增加运行依赖，也未改变API密钥存储或默认回环地址监听方式。
