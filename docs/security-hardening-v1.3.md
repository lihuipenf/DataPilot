# v1.3：外部审计逐项处理

日期：2026-11-05。基线：`3a02d3f`（1.2.1）。对应外部报告的3项Medium、16项Low。按单进程、单用户、回环监听的应用边界处理；风险等级不等同于已证明的任意远程攻击。

## 处理结果

| 编号 | 处理 |

| M-1 上下文预算 | 规范化消息与工具schema共用24000字符预算；单工具默认8000字符，完整行截断并标记truncated，SQL row_count同步更新。下一步继续分析已返回部分，不把截断清单当全集。预算在Settings统一配置；SQL256KiB仍作为底层资源上限 |

## 使用变化

升级前停止原生服务并备份完整outputs与.env。保留本地配置，更新代码后重新安装锁定依赖并重启。新增配置未填写时使用默认值，不覆盖已有.env。

```dotenv
DATAPILOT_MAX_CONTEXT_CHARS=24000
DATAPILOT_MAX_TOOL_RESULT_CHARS=8000
DATAPILOT_TURN_TIMEOUT=120
DATAPILOT_TRUST_ENV=false
DATAPILOT_MAX_SAVED_SESSIONS=200
DATAPILOT_MAX_SESSION_CHARTS=100
DATAPILOT_MAX_CHART_BYTES=268435456
```

配额满时，可先备份，手动整理运行数据或调整对应配置。程序不自动清理旧文件；已有历史超过会话数量配额时仍允许更新已有会话，但拒绝继续创建。32是内存缓存/待创建槽位上限，200是默认持久数量配额。

在POSIX共享主机上由所有者检查权限：`chmod 600 .env outputs/state.sqlite3`，`chmod 700 outputs`；其他父目录也应限制非授权用户访问。Windows检查项目与outputs目录ACL。默认单用户模式不能防御同账号恶意进程，不向共享主机/公网宣称已具备认证隔离。

## 验证与限制

最终本地全量98项测试通过，离线评测26/26通过；独立只读审阅复跑98项测试通过，未发现阻断问题。GitHub上另行验证Linux安装、公开依赖公告及容器启动。

- 新回归覆盖长商品SQL结果、schema预算、HTTP配置、尾斜杠/文件名、模式历史恢复、内存库拒绝、有界读取、连接关闭、Host、配额、慢恢复/慢上传并发、时间预算及进行中/空闲取消。
- Chromium验证普通聊天、停止后历史保留、上传、SQL截断提示；长商品名的桌面/手机横向溢出也加入检查并修正。
- 使用PyPI发行元数据中的全部平台发行物哈希；Windows用 `pip download --require-hashes --no-deps -r requirements-lock.txt` 验证所有37个包。Linux安装由CI验证；未声称在macOS实跑。
- CI运行pip-audit检查锁定依赖公开公告；Bandit以高危告警阻断，已审阅的中/低告警仍需人工复核。扫描失败不能证明绝对无漏洞。
- HTTPX超时主要限制网络阶段/读取空闲，持续流入响应、同步请求或绘图锁等待不能被此实现立刻中断。若需要严格墙钟上限/强制终止，需独立工作进程和请求取消协议。本版如实使用协作式停止；浏览器断开连接也不保证自动终止供应商已接受的付费请求。
- 配额和绘图锁面向一个服务进程；不启动多个Uvicorn worker共享输出目录来假定全局配额仍原子。不同进程或本机恶意文件写入不在当前配额协调范围。
- 没有改写Git历史、删除原始数据、轮换用户密钥或调用真实付费模型。
