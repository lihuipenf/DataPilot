# DataPilot v1.1 · 面向可维护分析产品

目标：学习成熟项目的架构方法，在现有销售分析场景中实现可解释、可恢复、可测试的能力，并发布到私有GitHub仓库。后续公开由项目所有者明确决定。

## 参考与独立实现

- [WrenAI](https://github.com/Canner/WrenAI)：学习将指标定义、业务含义和查询示例作为可审查文件管理的方式。
- [DB-GPT](https://github.com/eosphoros-ai/DB-GPT)：学习分层的数据访问、工具编排、执行证据和产品化交互。
- 参考设计思路，不复制其源码；本项目不声称具备它们的全部能力。

## 本轮交付

1. **语义层**：版本化的销售额、销量、均价等指标定义；提供模型可查询的字段和指标契约。
2. **SQL分析**：只读SQLite查询工具，展示SQL、列名、结果、耗时与截断信息；限制表、函数、返回行数和执行时间。
3. **持久会话**：将当前数据、完整对话轮次和问答证据存入本地SQLite；重启后恢复；界面可切换历史会话。
4. **持续交付**：跨平台依赖、自动化测试、Docker启动配置、GitHub Actions、贡献说明、变更记录和私有仓库发布。
5. **回归**：新增安全SQL、指标口径、重启恢复、不同数据规模的测试；保留原26题评测，明确各类指标边界。

## 边界

继续作为默认只监听本机的单用户应用，不将GitHub私有发布等同于公网部署。不会因此新增公网账户、多租户访问控制、任意Python执行或任意数据库连接。运行数据和密钥不纳入Git版本管理。
